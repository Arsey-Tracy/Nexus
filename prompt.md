# NexusCare UG

## NexusCareUG Patient features

Patient Schedules a consultation
Patient chooses between virtual or bedside nursing
Paient will then enter their details
submit a payment
Patient then receive a message of payment confirmation
Patients can add medical records, update their profiles
Patients can configure and set up preffered payments
patient can  view transactions status for payments
patient can not send messages to doctors
patient can configure setttings (privacy, notifications, account, etc)

NexusCareUG Doctor features
Doctor can register/ login
Doctor only views assigned patients
Doctor starts a consultation(call first, then virtual later)
if bedside nursing, Doctor will move directly to patient location from the submitted info
patient can view previous patients(beta feature once approved)
Doctor can set up their profile, upload valid documents for the admins to verify.
Doctor can customize app settinggs(notifications, theme(beta), account setings, availabilty(only admin views this for efficient assignments))
Doctor can log out

Doctor dashboard will not be active until all requirements are met for the doctor,
Requirements include

- Doctors must have a license that prove their qaulification via/from the umdcp.
- Doctors must provide valid id and a professional photo(no filters allowed or altered in anyway)
- Doctors must have a complete profile
- Doctor must upload their education profile, certificates, and education background
- Doctors must be approved by admin for the dashboard to unlock

NexusCareUG Admin features
Admin can register/ login
Admin can view all users(doctors, and patients) or user management
Admin can manually add new users
Admin can view all patient requests
Admin can assign doctors to patient requests
if bedside nursing, Admin views the nearest doctor and assigns them.
After Doctor consultation, Admin submits a payment after successful consultation.
Admin can view reports and analytics for data driven insights
Admin can view system health and submit features or bugs request to the developer
Admin can also update their profile
Admin can configure and updae thir settings,(notifications, user setings etc,) [also submit new settings to patients and doctors(beta)]

Other features,
Virtual consultations are recorded
Patients will be able to submit reviews improving user and platform trust
